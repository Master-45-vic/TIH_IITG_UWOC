# UWOC Bit Classification

In Underwater Optical Wireless Communication (UWOC), information is transmitted as binary bits (0 and 1) using optical signals. Water turbidity (NTU) causes absorption and scattering of light, which alters the received signal amplitude and makes fixed-threshold detection unreliable. This can lead to bit errors and inaccurate message recovery.

This project aims to develop supervised machine learning models that use received analog signal values and turbidity information to accurately classify transmitted bits under varying underwater conditions. The performance of machine learning approaches is compared with traditional fixed-threshold detection using standard classification and communication metrics.
